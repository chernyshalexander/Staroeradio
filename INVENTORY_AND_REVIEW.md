### Основные компоненты

#### 1. **Основной модуль (Plugin.pm)**
- **Инициализация плагина**: `initPlugin()` — регистрирует плагин в LMS
- **Обработчик меню**: `_feedHandler()` — главное меню плагина
- **API обработчики** (4 асинхронных метода):
  - `_apiPlaylistsHandler()` — получение плейлистов
  - `_apiProjectsHandler()` — получение проектов (Audiopedia)
  - `_apiRubricsHandler()` — получение рубрик
  - `_apiPlaylistTracksHandler()` — получение треков из плейлиста/проекта
- **Поиск**: `_searchHandler()` — поиск треков (2 режима: API и HTML scraping)
- **Живой эфир**: `_pollLive()`, `_parseLiveXML()` — обновление метаданных в реальном времени (15 сек интервал)
- **Прокси обложек**: `_coverProxy()` — ленивая загрузка обложек треков
- **Парсинг**: `_parseSearchResults()` — парсинг HTML результатов поиска
- **Форматирование**: `_formatApiTracks()` — преобразование данных API в формат LMS

#### 2. **Настройки (Settings.pm)**
Регистрирует следующие параметры в UI:
- `menuLocation` — Радио или My Apps
- `streamingQuality` — качество потока (highest/high/low)
- `descriptionInTitle` — показывать описание в названии
- `secondLineText` — содержимое второй строки
- `translitSearch` — транслитерация при поиске (англ→русс)
- `siteSelector` — выбор сервера (staroeradio.ru или staroeradio.com)
- `apiMode` — режим работы (API или HTML scraping)
- `useApiCoversInOldMode` — использовать обложки из API в режиме scraping

#### 3. **Встроенные каналы (Hardcoded)**
Статически определены 3 канала:
- **Vintage Radio** (`oldradio`) — старое радио 128/64/32 kbps
- **Vintage Children's Radio** (`childradio`) — детское радио
- **Vintage Music** (`oldmusic`) — музыка

### ⚠️ ПРОБЛЕМЫ И РЕКОМЕНДАЦИИ

#### 1. **Отсутствие обработки ошибок сети**
**Проблема**: При недоступности сервера плагин молча возвращает пустые результаты.

```perl
# Текущий код (строки 374-375):
sub { $cb->([]); }  # error callback просто возвращает пустой массив
```

**Рекомендация**: Добавить вывод дружелюбной ошибки в интерфейс LMS.

```perl
sub { 
    $cb->([{
        name => 'Ошибка подключения к серверу',
        type => 'text',
        webLink => 'http://server.audiopedia.su'
    }]);
}
```

---

#### 2. **Отсутствие пагинации (Pagination)**
**Проблема**: Все методы используют фиксированный лимит `limit=200`, что не масштабируется для больших коллекций.

```perl
# Строка 437:
my $url = "http://$host/getradioinfo.php?cmd=getTracks&limit=200&offset=0";
```

**Рекомендация**: Использовать параметры LMS `$args->{index}` и `$args->{quantity}` для вычисления `offset`:

```perl
my $limit = $args->{quantity} || 50;
my $offset = ($args->{index} || 0) * $limit;
my $url = "http://$host/getradioinfo.php?cmd=getTracks&limit=$limit&offset=$offset";
```

---

#### 3. **Потенциальная инъекция в парсинге HTML**
**Проблема**: В `_parseSearchResults()` название трека не санитизируется перед использованием в UI и `on_play` callback.

```perl
# Строки 591-593:
$title =~ s/^\s*<b>.*?<\/b>\s*//;
$title =~ s/\s*$$.*?$$//g;
$title =~ s/^\s+|\s+$//g;
# но нет защиты от потенциально опасного контента
```

**Рекомендация**: Хотя это маловероятно в контексте LMS, добавить явную санитизацию:

```perl
use Encode qw(decode);
$title = decode('UTF-8', $title);
# удалить любые управляющие символы
$title =~ s/[[:cntrl:]]//g;
```

---

#### 4. **Дублирование кода для выбора сервера**
**Проблема**: Логика выбора сервера повторяется в 6+ местах:

```perl
my $host = $prefs->get('siteSelector') eq 'staroeradio.com' 
    ? 'server.audiopedia.world:8888' 
    : 'server.audiopedia.su:8888';
```

**Рекомендация**: Извлечь в служебную функцию:

```perl
sub _getHost {
    my $is_com = $prefs->get('siteSelector') eq 'staroeradio.com';
    return $is_com ? 'server.audiopedia.world:8888' : 'server.audiopedia.su:8888';
}
```

#### 5. **Нет кэширования структуры меню**
**Проблема**: Каждое открытие Плейлистов/Проектов делает API запрос.

```perl
# Строки 353-375 и 378-400:
# _apiPlaylistsHandler и _apiProjectsHandler запрашивают API каждый раз
```

**Рекомендация**: Кэшировать на 24 часа (редко меняется):

```perl
my $cache_key = 'staroe_playlists';
my $cached = Slim::Utils::Cache->new()->get($cache_key);
if ($cached) {
    return $cb->($cached);
}
# ... выполнить запрос ...
Slim::Utils::Cache->new()->set($cache_key, \@results, 86400); # 24h
```

#### 6. **Потенциальная утечка памяти в полинге живого эфира**
**Проблема**: `%pollers` — глобальный хэш отслеживания полинга без явной очистки при отключении плагина.

```perl
my %pollers;  # строка 188 - глобальный хэш

sub shutdownPlugin { my $class = shift; }  # строка 149 - пусто!
```

**Рекомендация**: Добавить очистку при отключении:

```perl
sub shutdownPlugin {
    my $class = shift;
    %pollers = ();  # очистить все полинги
}
```

---

#### 7. **eval без обработки $@**
**Проблема**: JSON парсинг использует `eval { }` но ошибка при парсинге не логируется.

```perl
# Множество мест, например строка 360:
my $json = eval { from_json($http->content) };
if ($json && ...) { ... }  # молчит если парсинг упал
```

**Рекомендация**: Логировать ошибки:

```perl
my $json = eval { from_json($http->content) };
if ($@) {
    $log->warn("Failed to parse JSON: $@");
}
```

---

#### 8. **Потенциальная проблема с UTF-8 в HTML парсинге**
**Проблема**: В `_parseSearchResults()` декодирование идет в конце, но токены могут быть обработаны как raw bytes.

```perl
# Строка 594:
$title = decode('UTF-8', $title);  # В конце, но было собрано из сырых токенов
```

**Рекомендация**: Перемещение декодирования ближе к получению токена или использование `Encode::decode_utf8`.

---

#### 9. **Жестко закодированные каналы не синхронизируются с API**
**Проблема**: 3 канала в `$cachedChannels` (строки 52-92) не получаются из API, это статические данные.

```perl
my $cachedChannels = [
    { "id" => "oldradio", "title" => "Vintage Radio", ... },
    # ... статические данные ...
];
```

**Рекомендация**: Если эти каналы могут меняться, загружать их из API при инициализации.

#### 10. **Отсутствие таймаутов для асинхронных запросов**
**Проблема**: `SimpleAsyncHTTP` использует константу `HTTP_TIMEOUT => 15`, но она не применяется явно.

```perl
# Строка 33: определена константа, но не видно явного применения в вызовах
use constant HTTP_TIMEOUT => 15;
```

**Проверка**: В `SimpleAsyncHTTP->new()` нет явного параметра `timeout`. Нужно проверить, использует ли он константу автоматически.

### 🎯 КРИТИЧЕСКИЕ НАЙДЕННЫЕ ОШИБКИ

#### Ошибка 1: `$getStream` получает неправильный параметр
**Строка 342**:
```perl
my ($channel) = shift;  # ❌ Неправильно! Должно быть: my $channel = shift;
```
Здесь `shift` возвращает scalar, а `my ($channel)` создает array context, что может привести к ошибке.

**Исправление**:
```perl
sub _getStream {
    my $channel = shift;  # ✅ Правильно
```

---

#### Ошибка 2: `HOST_CONFIG()` вызывается как функция, но это константа
**Строка 558**:
```perl
for my $pattern (keys %{HOST_CONFIG()}) {  # ❌ HOST_CONFIG это константа!
```

`HOST_CONFIG` — это HASH constant (строка 38), вызывается с `()`. Это работает в Perl, но стиль странный.

**Рекомендация**:
```perl
for my $pattern (keys %HOST_CONFIG) {  # ✅ Более правильно
```
